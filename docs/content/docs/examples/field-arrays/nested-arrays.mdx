## What this shows

A field array inside a field array. Each section row renders its own `useFieldArray` for its lessons, with the section row as its `ancestors`. See [Nested field arrays](/docs/guides/field-arrays#nested-field-arrays).

- Fields in a lesson list every row they're inside, outermost first.
- Initial values and submitted values include the nested lessons.
- The inner array's `defaultValue` gives a new section its first lesson.
