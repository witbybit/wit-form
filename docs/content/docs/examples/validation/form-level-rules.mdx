## What this shows

[`useForm({ validate })`](/docs/api/use-form#validate) receives every value and returns a list of messages, for rules that span several fields like a date range or a guest limit.

It runs on submit together with field validation. `onError(fieldErrors, formErrors, values)` receives both kinds of error, so the form can show a summary.
