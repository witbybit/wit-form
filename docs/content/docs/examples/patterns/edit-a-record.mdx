## What this shows

Load a record, edit it and save it. See [Loading and Saving Data](/docs/guides/loading-and-saving).

- [`resetInitialValues(record)`](/docs/api/use-form#resetinitialvalues) loads fetched data as the new initial values.
- [`useIsDirty()`](/docs/api/watch-hooks#useisdirty) enables Save only when something changed, and `handleReset()` discards the edits.
- When the save fails, `onSubmit` resolves to `false`, so the initial values are kept and the edits stay.
- `checkIsDirty()` asks before switching to another record.
