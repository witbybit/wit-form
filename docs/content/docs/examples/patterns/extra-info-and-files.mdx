## What this shows

Every field stores a value and an optional [extra info](/docs/core-concepts#4-each-field-has-a-value-and-an-extra-info). The value holds what the API needs and the extra info holds what the UI needs: a member's name and colour, or a `File` and its preview URL.

`setFieldValue(value, extraInfo)` sets both. `onSubmit(values, extraInfos)` receives both, with `extraInfos` shaped like `values`.
