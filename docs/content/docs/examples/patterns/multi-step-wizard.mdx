## What this shows

A long form split into steps that share one `useForm`.

- [`skipUnregister: true`](/docs/api/use-form#skipunregister) keeps values from steps that are no longer rendered.
- [`validateFields(names)`](/docs/api/use-form#validatefields) validates only the current step before moving on.
- The review step reads everything with [`useFormValuesAndExtraInfos`](/docs/api/watch-hooks#useformvaluesandextrainfos).
