## What this shows

[`useFieldWatch`](/docs/api/watch-hooks#usefieldwatch) subscribes small components to the answers that control follow-up questions, so the rest of the form doesn't re-render.

When a field unmounts its edits are discarded, so hidden answers never reach `onSubmit`. See [Core Concepts](/docs/core-concepts#6-fields-come-and-go).
