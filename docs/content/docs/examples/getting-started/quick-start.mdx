## What this shows

The smallest complete form: a field component built with [`useField`](/docs/api/use-field), a form built with [`useForm`](/docs/api/use-form), and a [`FormProvider`](/docs/api/form-provider) around both.

- Field names are paths, so `address.city` creates `{ address: { city } }`.
- `onSubmit` returns a promise, so `formState.isSubmitting` stays `true` until it settles.
- `error` is only set once a field is touched: after it's blurred or the form is submitted.
