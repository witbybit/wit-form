## What this shows

[`<Field>`](/docs/api/field) connects inputs without writing a hook per input.

- **Child element:** `<Field>` passes `value`, `onChange(event)`, `onBlur`, `error`, `touched` and `extraInfo` to its child.
- **Render function:** `onChange` takes the new value directly, which suits radios, checkboxes and custom widgets.
- `required` adds a "Required" check when there's no `validate`.
- [`withFormProvider`](/docs/api/form-provider#withformprovidercomponent-options) wraps the form in a `FormProvider`.
