## What this shows

Every field is its own Jotai atom, so typing in one cell re-renders that cell and its column total. Nothing else re-renders, whether the table has 100 rows or 500. See [Performance](/docs/guides/performance).

- Each column total watches only its column with `useFieldArrayColumnWatch`.
- The array has no `validate`, which would subscribe it to every value.
- [`skipValuesObserver`](/docs/api/form-provider#skipvaluesobserver) turns off whole-form value tracking, since nothing here uses `useFormValues` or `useIsDirty`.
