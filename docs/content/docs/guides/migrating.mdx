## From react-recoil-form

Wit Form is the successor to react-recoil-form. It has the same API, with Jotai in place of Recoil, and it works on React 18 and newer.

1. Swap the dependencies:

   ```sh
   pnpm remove react-recoil-form recoil
   pnpm add wit-form jotai
   ```

2. Change your imports:

   ```diff
   - import { useForm, useField } from 'react-recoil-form';
   + import { useForm, useField } from 'wit-form';
   ```

3. Remove any `RecoilRoot` you added only for forms. Each `FormProvider` creates its own store.

That's all most apps need. Hooks, options and return values have the same names and behaviour.

`FormProvider`'s `skipRecoilRoot` option still works, as an alias of the new name `skipJotaiProvider`. Both keep the form's state in the surrounding Jotai store instead of a new one. See [FormProvider](/docs/api/form-provider).

## From Formik

Most Formik concepts have a direct counterpart:

| Formik                                            | Wit Form                                                          |
| ------------------------------------------------- | ----------------------------------------------------------------- |
| `<Formik>` or `useFormik`                         | A [`FormProvider`](/docs/api/form-provider) with `useForm` inside |
| `<Field>`, `useField`                             | [`useField`](/docs/api/use-field) or Wit Form's `<Field>`         |
| `<FieldArray>`                                    | [`useFieldArray`](/docs/api/use-field-array)                      |
| `validationSchema`                                | `useForm`'s `schema`. A Yup 1.7+ schema works as is.              |
| `setFieldError`                                   | `setError`                                                        |
| `isValid`, `dirty`, `submitCount`, `isSubmitting` | `formState.isValid`, `isDirty`, `submitCount`, `isSubmitting`     |

`initialValues` and `onSubmit` keep their names. Field names are paths, like `address.city`, but fields inside a list use plain names with `ancestors`. See [Field arrays](/docs/guides/field-arrays).
